# Design Skill

## Trigger

Executada pelo implementer-agent quando é necessário realizar trabalho de design, arquitetura ou modelagem de componentes.

## Description

Realiza o trabalho de design e arquitetura para as mudanças propostas no plan. Define estruturas, padrões de código, e decisões arquiteturais antes da implementação.

## Capabilities

- Architecture design
- Component modeling
- Pattern selection
- Interface definition
- Dependency structuring

## Usage

O implementer-agent deve carregar esta skill antes da implementação para garantir que as decisões de design estejam alinhadas com o plan.
